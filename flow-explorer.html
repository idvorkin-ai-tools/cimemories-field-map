Contextual integrity says a flow of information is appropriate when it matches the norms of the context it happens in. Whether the information is secret has nothing to do with it.     How CIMemories uses this

    In CIMemories three of the five parameters are fixed. The sender is always the assistant writing for the user, the subject is always the user, and the information type is one remembered attribute. Only the task varies, and it brings the recipient and the purpose, which stands in for the transmission principle. So every (attribute, task) pair gets its own label. Pick a memory and a task:

    The table is the paper's idea in small: no row is all green or all red, so no fixed "private" label works for any memory. CIMemories scores a model on both sides of it. Revealing a red cell counts toward Violation@n, and leaving out a green cell costs completeness. With about 147 attributes and 45 tasks per person, a model has to get thousands of these cells right, and the paper finds every model tested gets many wrong (Part 06).
